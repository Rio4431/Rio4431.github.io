Transcriptome analysis

Cellular Senescence Transcriptome Analysis

ヒト皮膚線維芽細胞のNormal・Senescence・Treatment条件を比較し、老化に伴う発現変化とTreatmentによるNormal方向への変化を探索。

Objective
老化関連遺伝子とTreatmentによる回復候補を探索。
Data
Private microarray expression dataset
Methods / Technologies
Python / Microarray / Fold-change analysis / GO enrichment / Fisher's exact test / FDR / Visualization
Analysis
QC → 2-fold変動遺伝子抽出 → Normal方向への回復評価 → GO解析 → 候補遺伝子整理
Summary
718遺伝子から、Normal方向へ変化した181遺伝子を抽出し、51遺伝子の強いTreatment応答サブグループを整理。
